MoonClear

A simple brutalist directory of useful websites. It includes torrent sites, streaming platforms, direct download links, software, games, books, anime, music, and privacy tools.

What is here
- Torrents and tracker indexes
- Streaming sites for movies and TV
- Direct download links for games and software
- Book and article sources
- Anime and music resources
- Essential tools like VPNs and ad blockers

How to use
Open index.html in any browser. Use the search bar to filter sites by name, category, or URL. Click COPY to copy a link, or VISIT to open the site.

Notes
All links point to official or widely trusted domains. Domains can change, so check a trusted directory if a link stops working. This site does not host any files. Use the tools and links at your own risk.
